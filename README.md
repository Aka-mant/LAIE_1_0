# LAIE 1.0 — Local Autonomous Edition

Автономная локальная исследовательская система для анализа истории лотереи
«Рапидо Про», проверки статистических гипотез и формирования портфелей в рамках
лимита 5 000 рублей на тираж.

## Архитектура

- Windows x64; Django web UI доступен только через loopback.
- Локальная PostgreSQL — основная база данных; удалённые DB hosts блокируются.
- CPU поддерживается всегда; NVIDIA CUDA через PyTorch — опциональное ускорение.
- Нет облачных workers/jobs, удалённых вычислений, внешних AI API или облачной БД.
- После установки и локальной загрузки истории Интернет не нужен для вычислений и анализа.
- Обновление истории — только по инициативе пользователя.
- Покупка билетов — исключительно вручную.

## Научное ограничение

Лотерея является случайной игрой. Исторические частоты и найденные закономерности
не доказывают предсказуемость будущих тиражей. Методы сравниваются с равномерным
случайным baseline на независимых временных выборках. Система не обещает прибыль.

## Статус

LAIE остаётся развиваемым каркасом. Наличие базового ComputeEngine не означает,
что все доменные задачи уже переведены на GPU. До промышленного использования
нужно завершить доменные приложения, импорт истории, интеграцию вычислительного
движка, мониторинг ресурсов, интерфейс и тестирование на целевой локальной БД.
